# Codex · 随行

面向 Android 17 的中文原生编程助手，在手机上管理项目、运行工具和保存会话，无需电脑充当运行核心。

**当前状态：开发中的 0.1.0，尚未完整复刻 Codex。原版 Rust 引擎没有嵌入 APK。** 这里根据上传源码的会话、工具、审批与回注语义实现 Kotlin 适配；不能把它宣传为官方 Codex 安卓版或等同于原版全部能力。

## 使用

1. 安装构建生成的 APK，打开侧栏 → 项目文件，导入文件或创建项目。
2. “连接与偏好”中填写 Responses API 地址、密钥，获取/选择可用模型。需要有权限和额度的 API 账户；ChatGPT 订阅登录尚未实现。可以连接手机本机兼容模型服务，不依赖电脑。
3. 发起任务；助手会读取项目、请求修改或执行命令。文件修改显示差异，命令展示内容，确认后才执行。
4. “查看修改”可以撤销本次变更；外部或后续编辑改变了文件时，撤销会停止以避免覆盖。
5. “本机终端”直接使用手机系统的 shell；不自带桌面 Python/Node/Linux 发行版。

模型服务通常需要网络。“手机独立运行”不表示内置离线大模型；没有模型连接时不会显示虚构回答。

## 已实现的范围

- 中文侧栏、项目/会话切换、标题搜索、归档/恢复、重命名、分叉、任务目标；会话分类的增删改、筛选和移动，最近任务文件修改回滚。
- 深浅双主题、系统返回、键盘避让、流式正文、代码复制、工具折叠、修改审批。
- 本机文件目录元信息列表、按行读取/搜索、编辑/导入/导出，Begin Patch 格式的新增/修改/删除与冲突检查；文件/目录复制、递归删除和元数据查询。
- Responses SSE → 函数调用 → 本机工具 → 审批 → 结果回注；上下文摘要压缩、运行中追加指令、工具状态持久日志与中断保守恢复。API 错误和断流显示失败，拒绝操作无副作用。
- 原生进程组执行与取消、输出上限、命令超时、前台任务通知；JNI PTY 持续 shell 的输入、窗口尺寸变化、Ctrl+C 和关闭。终端内容当前以纯文本展示，复杂终端仿真尚未实现。
- 本地技能指令和项目额外技能目录配置、工作计划、JGit 本地仓库操作；无认证 HTTPS Streamable HTTP MCP 的工具和资源。
- API 密钥由 Android Keystore 加密保存，应用禁止系统备份。

## 未完成与平台差异

详见 [源码功能对照](文档/源码功能对照.md) 与应用内“功能与限制”。对照表枚举了上传版本 ClientRequest.ts 的全部 109 项请求，但并非 Codex 的完整功能全集，也不是 JSON-RPC 兼容承诺。

待移植包括：原版 Rust 执行内核及 App Server、ChatGPT OAuth/订阅认证、完整终端仿真、模型路由/配额、上游全部上下文压缩策略、Git 网络认证/推送、MCP OAuth/stdio、插件市场、Hooks、多代理、云任务与实时语音。它们不能笼统归为“安卓不支持”。

安卓系统差异：无桌面 Landlock/bubblewrap/Windows/macOS 沙箱；应用不能访问其他应用私有目录；后台执行受系统限制；桌面可执行程序需重新编译或提供运行环境。当前 shell 只受 Android UID 约束，**不是项目目录沙箱**。

## 构建

完整 JDK 17、Android SDK 37.0、Build Tools 37.0.0、NDK 28.2.13676358、CMake 3.22.1。

```bash
cd 安卓Codex
./gradlew :core:test :app:lintDebug :app:assembleDebug
```

安装包：`app/build/outputs/apk/debug/app-debug.apk`。开发签名仅供测试，不用于应用商店发布；后续正式签名须由仓库所有者配置。

设备测试：启动 Android 17 模拟器/设备后运行 `./gradlew :app:connectedDebugAndroidTest`。当前原生 ABI 为 arm64-v8a 与 x86_64，面向 2026 年中高端手机；帧率、发热与功耗必须在实际目标硬件上测量，不能据此声称已达 120 帧。
