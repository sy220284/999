仍缺受认可的外部刷新/证明提供者；固定原版预测请求本身未实现；复杂表单的外部/动态资源规则有限。语言环境不等于完整桌面软件仓库，npm脚本及第三方原生扩展未等价实现。本机创建验证凭证不代表服务端登记。

**手机命令共享本应用UID，不是项目级进程沙箱。** 桌面可执行程序不能直接复制运行；Windows/macOS/Linux桌面沙箱机制不能直接等价使用。后台执行受Android及厂商策略约束。应用禁止系统备份，密钥使用Keystore；这不意味着同UID命令已被隔离。
