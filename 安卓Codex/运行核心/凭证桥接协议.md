# Android 凭证桥接

接口：Rust `android_keyring.rs` ↔ Android `OriginalVaultServer` ↔ `OriginalCredentialVault`。

仅本机 Unix stream socket，地址位于应用私有 cache 目录、每次启动随机生成。宿主启动 socket 后创建原版进程，再授权其确切 PID；启动竞态最多等待 10 秒。宿主检查调用者 UID/PID，Rust 检查宿主 UID/PID（SO_PEERCRED），同 UID 工具子进程也被拒绝。

## 帧

请求：版本 `u8=1`、操作 `u8`、service、account、value。每个文本字段都是大端 `u32` 字节长度加 UTF-8；身份字段上限 4096 字节，值上限 1,048,576 字节。service/account 非空且不含 NUL。一次连接处理一次请求。

响应：状态 `u8`、大端 `u32` 长度、UTF-8 内容。状态定义：

| 状态 | 含义 |
|---|---|
| 0 | 查询无记录 |
| 1 | 查询命中，内容为凭证值 |
| 2 | 保存成功 |
| 3 | 删除成功 |
| 4 | 删除时无记录 |
| 255 | 身份拒绝、非法请求或存储失败；消息不含凭证及平台异常链 |

操作码为 1 查询、2 保存、3 删除。读取和写入均设超时；不重放保存/删除请求。服务顺序执行，防止刷新与删除在宿主内并发覆盖。

## 密文

noBackupFilesDir 下，以 SHA-256(service + NUL + account) 命名。文件为版本字节 `1`、12 字节随机 IV、AES-GCM 认证密文；同一身份作为 AAD。密钥保留在 Android Keystore，文件使用 AtomicFile 提交。原版账号与 MCP 强制 keyring，后端错误不降级到文件存储。

该桥接没有增加项目沙箱；同应用 UID 下的命令仍拥有本应用权限。跨语言调用、系统 socket 行为、密文恢复及异常场景均等待后续编译/设备验证，本阶段只有源码和静态检查。
