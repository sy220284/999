# 构建环境记录

- 目标 Android 17/API 37，compileSdk/targetSdk/minSdk 均为 37。
- SDK Manager 的实际平台包名是 platforms;android-37.0，不是 platforms;android-37。
- 初始 AGP 8.13.2 的 D8 提示最高支持 API 36，已改用官方支持 API 37.0 的 AGP 9.2.1、Gradle 9.4.1、Kotlin 2.3.10（Android 模块使用内置 Kotlin）。
- 原环境只有 Java 17 JRE，无 javac；构建使用完整 Temurin JDK 17。
- 网络代理端口按每次执行环境读取，不能复用上一进程的 Gradle daemon；本环境用 --no-daemon。仓库不写入临时代理配置。
- 本环境下载的 JDK 需用系统 Java 信任库验证代理证书；生产应用不修改 TLS 验证。
