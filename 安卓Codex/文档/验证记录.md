- Figma Starter MCP 调用配额耗尽；已创建的文件没有设计画面，未将其算作设计交付。
- 当前覆盖不等于完整复刻，未实现部分见《源码功能对照》。

## 已定位并修复的实际问题

1. Linux JVM 取消时只终止父进程，后台 sleep 保持输出管道；改为 setsid 与进程组终止后，取消测试从失败变为通过。Android 采用 JNI 的独立会话/进程组实现，还需设备验证。
2. 补丁若后续块不匹配不能先创建前面的文件：完整预演后统一提交，冲突测试确认没有部分写入。
3. 修改历史按项目隔离，切换项目不会把同名文件的撤销记录串在一起。
4. 服务结束前先刷新会话，再解除运行状态，避免新任务恰在旧服务结束时丢失。
5. AGP 升级后的旧增量输出导致重复声明；清理 app 输出后完整编译通过，没有新增重复业务实现。
6. 网络安全配置补齐 includeSubdomains=false；设置 Android 12+ 数据提取规则，关闭云备份与设备迁移。

设备环境排障：系统日志确认 `WATCHDOG KILLING SYSTEM PROCESS`，不是应用崩溃。仅在临时模拟器调整测试环境的启动超时，尚未修改产品行为或虚构启动完成标志。
