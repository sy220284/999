### P0 状态组件的接口约定

`OriginalLifecycleState` 字段：`connectionEpoch: Long`、`threadId: String?`、`turnId: String?`、`pendingStartRequestId: String?`、`stoppingTurnId: String?`、`completedTurnIds: Set<String>`。完成 ID 集合只保留最近 128 项，断开连接后清空；所有状态更新在宿主单一调度上下文完成。

`OriginalLifecycleEvent` 为 sealed interface，有字段的事件定义为 data class，无字段事件定义为 data object：

- `ThreadSelected(threadId: String, activeTurnId: String?)`：恢复已有线程，不发送新任务。
- `StartRequested(requestId: String)`：原版请求前由宿主生成逻辑 UUID，写入 pending；已有活动回合或 pending 时拒绝另启。
- `StartResponded(requestId: String, threadId: String, turnId: String)`：只匹配当前 pending；已完成的 turnId 不重新激活。
- `TurnStarted(threadId: String, turnId: String)`：匹配当前线程且不属于已完成集合时更新活动回合。
- `TurnCompleted(threadId: String, turnId: String)`：加入完成集合，只清除同 ID 活动/停止状态，不影响其他回合。
- `StopRequested(threadId: String, turnId: String)` / `InterruptAccepted(threadId: String, turnId: String)`：仅标记对应回合停止中，收到中断请求响应不能代替完成通知。
- `Disconnected`：清除当前连接的 pending 和活动状态，由宿主另行回收进程与 socket。

测试最先补 `staleEpochIsIgnored`、`completedBeforeStartResponseStaysIdle`、`completionOfADoesNotClearB`、`disconnectClearsPending`、`resumeDoesNotEmitStart`；分别断言状态不变、turnId=null、turnId=B、pending=null、宿主发出的 turn/start 次数=0。
