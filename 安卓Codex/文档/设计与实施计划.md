# 安卓 Codex：设计与实施计划

用户已选定手机独立运行。平台 Android 17 / API 37，面向 ARM64、8–16GB 内存的中高端手机；不把硬件年份当成性能保证，需实机测量帧率。

## 交付约束
中文 UI、项目/会话侧栏、深浅主题、系统返回、键盘和安全区、可关闭动效、真实文件与执行链。999 仓库原有内容保留，新增独立目录。禁止把演示数据或未实现功能标成完成。

## 架构取舍
上游 Rust 工程含桌面 PTY、平台沙箱、V8、桌面凭证与进程依赖，无法直接当 Android 库链接。原生 Kotlin 实现本地会话与 Responses 工具循环；参照上传版本的工具、审批、回注与会话语义。它是安卓功能适配实现，不冒称原版 Rust 引擎已完整移植。模型通常联网调用；“独立运行”指不依赖电脑，不等于手机离线运行大模型。

## 界面
石墨深色、暖白浅色、青绿强调色。侧栏：新对话、项目、会话搜索/归档、文件、终端、技能、MCP、设置、能力说明。主界面以内容为主，工具执行折叠，审批以底部弹层展示具体命令/修改；输入区固定在键盘上方。平板宽屏保留侧栏，手机抽屉打开。

动效：侧栏位移与遮罩、页面淡入位移、工具卡展开、发送/停止切换、列表位置动画；使用 Compose 系统动画倍率，关闭系统动画时停止过渡。按压与触觉反馈统一。长列表懒加载，文本流按帧合并，不逐字符写盘。

## 执行任务
1. 建立 core JVM + 原生 Compose app 与可重复构建，先写行为测试。
2. core：SSE、Responses 函数调用循环、审批、取消、文件/补丁、shell、持久会话/分叉/归档、技能与计划；验证取消与越界文件访问。
3. app：安全保存凭证、前台执行服务、侧栏/对话/文件编辑/差异/终端/设置；文件导入导出与附件，Git、MCP 连接。
4. 对照上传源码生成完整接口清单，逐项标明可用、部分适配、待实现、安卓限制；未实现不得归因于安卓不支持。
5. 编译 APK、单元测试、界面截图与交互检查；能获取模拟器则执行 UI 回归，否则准确记录未验证项。
6. 中文提交与 PR 写入 999，读取远端提交复核；构建结果与未完成项明确记录。

## 验收重点
没有 API 凭证时不展示假回复；取消要终止请求/命令；审批拒绝无副作用；路径穿越/符号链接不能越过工作区；服务重建不自动重放工具；历史保存原子化；断网与 API 错误保留用户输入；大文件显式受限而非卡住；不声称拥有桌面级 shell 沙箱。

## 进度
初始：需求明确，源码和仓库已核对；Figma 文件已创建，Starter 调用配额耗尽，尚无设计画面。以原生应用实际界面为验证对象。
