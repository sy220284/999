# 法律联网搜索

调用前读取[方法与输入输出](references/contract.md)。优先构造包含发布机关、文件名称、核心概念和时间范围的查询。由主Agent编排本Skill。需要正文时可在本次搜索中启用`fetch_content`，但这不等价于按任意URL读取网页。

## 工作要求

1. 优先政府、人大、法院、检察院、监管机构和企业公告等第一方来源。
2. 仅返回标题、URL和摘要时，结果只用于定位；返回真实`content`时可据其核对正文，但仍应核对发布主体、日期和最终URL。
3. 域名过滤只有在后端确认实际执行时才能称为硬过滤；否则仅视为搜索偏好。
4. `preferred_source_types`只表示排序偏好，除非后端明确支持，不得声称已经按来源类型过滤。
5. 去除明显重复、聚合转载和与查询无关的结果；只返回真实URL。
6. 搜索无结果时可调整关键词一次；仍无结果则如实返回，不编造来源。

## 执行方式

使用`scripts/client.py`调用清言联网搜索入口。当前真实响应把阅读器格式文本放在顶层`result`中，脚本将其解析为结构化结果；同时兼容文档字段表所述的`result.data[]`，便于后续接口修正后联调。调用方不携带服务凭证。

当前接口不支持域名、时效和来源类型硬过滤，相关输入只能返回未执行警告。不能因搜索结果看起来像官方网站，就自动标记为第一方来源。
