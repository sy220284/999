# 律师函（及催收函/告知函/回函/通知书共用骨架）

依据：上海律协《律师签发律师函业务操作指引（2021）》（下称"指引"），尤其第 12-15、20 条范例。

## 一、体例骨架（自上而下）

1. **律所抬头**：正文首页顶部为律所全称大字（居中），已知英文所名的可在其下加一行小字英文所名，抬头与标题之间用一条分隔线区隔；页眉使用律所全称（不是"律师函"三个字）。题目给了律所名称就必须做抬头，这是律师函区别于普通函件的门面要素。
2. **标题/编号**：居中标题"律 师 函"（或"关于××事宜的律师函"）；下一行函号：`（20XX）××律函字第____号`。编号未知时必须用下划线显式留白（"第____号"），**禁止用空格占位写成"第　号"——看起来像漏填，属不可交付缺陷**；不得编造具体序号。无编号制度时可整行省略。
3. **致送对象与地址**：顶格 `致：××公司`（收件人全称，不用简称），下一行写收件地址（题目给了地址必须写入）；寄送地址、联系电话在落款后单列
4. **委托来源段（引言）**：本所主体资格 → 受××委托/作为××常年法律顾问 → 指派××律师就××一事 → 依据《××法》及相关法律法规 → "特向贵司致函如下"
5. **事实与法律评价段（正文一、二）**：
   - 一、委托人陈述的基本事实：按时间顺序叙述，须冠以"根据委托人向本所提供的事实及证据"；证据不足时加"以上事实正在进一步调查取证中"
   - 二、法律分析及法律后果：适用法条 → 论证 → 对方行为性质及可能承担的法律责任；不得对法院未裁判事实作肯定结论。**告知类函件（仅告知案件受理、邀请对账/和解等克制场景）省略实体违约责任论证——引条文分析责任带施压意味，与告知目的相悖**
6. **要求与期限段（正文三）**：明确解决方案与步骤（"请贵司在收到本函之日起×日内履行……"）；提示不回复/不履行的后果（分歧加深、将通过诉讼等法律途径维权）
7. **两条标准声明**（指引第 15.1 条，宜原文照录）：
   - "本律师函作出法律分析所依据的事实系由委托人提供，并不排除与客观事实有所出入的可能。贵方如对本律师函涉及事实有异议，或对问题的解决有其他合理建议，请直接与本律师联系沟通。"
   - "本律师函不得以任何方式被解释为委托人对权利作任何放弃、义务作任何增加。"
8. **落款**："特此函告！" → "此致" + 受函人 → 律师联系方式、委托人联系方式 → **律师事务所公章 + 经办律师律师章（双章，缺一不可）** → 签发日期
9. **尾注**：寄送地址 / 联系方式 / EMS 单号 / 附件（如有）

## 二、必备要素清单

- [ ] 律所抬头（所名大字居中；页眉为所名而非文书种类）
- [ ] 标题与函号（函号用"第____号"显式留白或完整编号，禁止"第　号"空格占位）
- [ ] "致：" + 收件人全称 + 完整可送达地址、联系电话
- [ ] 律所主体资格与委托来源（单项委托 / 常年法律顾问，二选一表述）
- [ ] 经办律师姓名、针对事项、法律依据（引言三要素，指引第 13 条）
- [ ] 事实综述（时间/地点/人物/事件，冠"据委托人提供"）
- [ ] 法律分析与法律后果
- [ ] 具体要求 + 履行期限 + 不履行后果提示
- [ ] 两条标准声明（逐字）
- [ ] 律师及委托人联系方式（回复渠道）
- [ ] 律所公章 + 律师签名章、日期
- [ ] 附件清单（如有）

## 三、填写要点

- **收件地址完整转写**：从委托人材料/工商登记中取对方注册地址+实际经营地址，完整写入尾部"寄送地址"，勿缩略；EMS 面单载明文件名"××致××关于××的律师函"（指引第 18 条）
- **函号占位**：模板中用 `（20XX）××律函字第____号` 下划线留白，签发时按律所编号规则填写；不得为"真实感"编造具体序号，也不得留空格
- **期限表述**：用"自收到本函之日起×日内"，不用绝对日期（送达日不可控）；期限应合理（常见 3/7/10/15 日）
- **回复渠道**：律师姓名、手机、邮箱、律所地址逐项列明；要求书面回复的写明接收方式
- **事实措辞**：只作叙述与法律评价，不作侮辱、威胁性表述；未经委托人同意不得自行提出和解/处置方案（指引第 14.3 条）
- 范例中"一、二、三"纲要语句无须照搬，按该结构表述即可（指引第 20 条提示）

### 函件版式与表格边界

- 律师函优先采用清晰的律所抬头、函号、收件人、连续正文、回复渠道和双章落款。标题下不要增加封面，正文前不要放案件信息总表。
- 收件人名称、地址和联系方式可以各用一个紧凑段落；不要把少量收件信息做成表格。
- 事实、法律评价、要求事项和标准声明保持书信体段落或必要的编号，不因含有多个事项就表格化。
- 单一本金、一个付款期限或一组联系方式用文字表达。只有债务由多个合同、发票、付款、利息期间或抵扣项目组成，确需对账时，才使用金额明细表或将其作为附件。
- 律师函通常应控制在适当篇幅内。法条只保留支撑函件要求的直接规则，不另设冗长“法律依据汇编”或为显示专业性增加无关表格。

## 四、各函种差异表（共用上述骨架）

| 函种 | 目的（指引第 2 条对应项） | 正文侧重 | 要求段写法 | 特殊点 |
|---|---|---|---|---|
| 催收函/催告函 | 要求履行金钱给付/交付财产 | 债权凭证、欠付金额、利息/违约金计算 | 限期付款至指定账户（户名/开户行/账号） | 注明款项构成明细；可载明将主张的诉讼费用 |
| 告知函 | 向第三方通知事项/披露信息 | 客观陈述需告知的事实与法律状态 | 可无强制要求段，代之以"请知悉/请配合" | 评价性内容最少化 |
| 解除/通知书类 | 通知解除合同或改变法律状态 | 合同依据条款 + 解除事由 + 解除权来源法条 | 明确解除生效时间（通常"自本函送达之日起"）、后续清算/交接要求 | 形成权行使，送达即生效，务必保全送达证据 |
| 回函/复函 | 回应对方来函 | 引述来函（日期/编号/主张）→ 逐项回应、澄清或反驳 | 表明己方立场与保留权利 | 标题作"复函"；开头"贵所/贵司××年×月×日函悉" |

差异只在第 4、5 段（事实评价与要求段）；函头、委托来源段、两条声明、双章落款各函种一致。

## 五、被迫解除劳动合同通知书（劳动者单方解除，特别体例）

由劳动者本人签发（非律师函，无双章，仅劳动者签名/捺印），但沿用"致送对象 → 事实 → 法律依据 → 要求 → 落款"骨架。必备要素：

1. **标题**：《被迫解除劳动合同通知书》或《解除劳动合同通知书》，避免"辞职申请""望批准"等协商性措辞（解除权为形成权，通知即生效，无需单位同意）
2. **双方主体信息**：单位全称；劳动者姓名、身份证号、入职日期、岗位、合同期限
3. **解除依据条款**：《劳动合同法》第三十八条，并**具体到项**（如第一款第二项"未及时足额支付劳动报酬"、第三项"未依法缴纳社会保险费"）
4. **事由陈述**：具体化违法事实（如"拖欠 20XX 年 X 月至 X 月工资共计 X 元"），忌笼统；对应证据（工资流水、社保记录、考勤）另行留存
5. **解除日期**：明确"自本通知书送达之日起解除"或具体日期
6. **要求事项**：一次性结清工资及加班费（《工资支付暂行规定》第九条）；支付经济补偿（《劳动合同法》第四十六条第一项、第四十七条）；出具解除证明并 15 日内办理档案和社保转移（第五十条）；安排工作交接
7. **送达要求**：一式两份，一份 EMS 邮寄至单位注册地址（面单品名栏注明"被迫解除劳动合同通知书"），保留邮寄凭证与签收记录；当面递交的请接收人签字
8. **落款**：劳动者签字（捺印）+ 日期

注意：暴力强迫劳动、违章指挥危及人身安全情形可立即解除、无需事先告知（第三十八条第二款）。

## 六、常见错误

1. 缺两条标准声明之一（尤其"不得解释为权利放弃"条）——留下权利放弃/义务加重的解释空间
2. 只盖律所公章、漏经办律师签名章（或反之）
3. 事实段未冠"根据委托人提供的事实及证据"，将委托人陈述表述为律师查明的事实
4. 对未决事实作肯定性结论（"贵司已构成诈骗"），或使用威胁、侮辱性语言
5. 期限用绝对日期而非"收到之日起×日"，或未给回复渠道
6. 收件地址不完整/仅写简称，导致退件且无送达证据；未留存 EMS 底单与函件复印件（指引第 18-19 条）
7. 未经委托人确认定稿即签发（指引第 17 条）
8. 被迫解除通知书用"申请/请求批准"措辞，或未写明第三十八条具体项、未保留送达凭证——仲裁中难以证明"被迫"解除事由
9. 把律师函写成报告：增加封面、案件信息表、时间线表和法律依据表，冲淡收件人、要求与履行期限
10. 缺律所抬头、页眉写"律师函"而非所名、函号用空格占位"第　号"——门面要素缺失，收件方一眼判定为草稿
