# 民事起诉状 / 民事答辩状 官方示范文本参考

依据最高人民法院、司法部、中华全国律师协会联合印发的要素式起诉状、答辩状示范文本整理。
现行版本为《关于印发部分案件起诉状答辩状示范文本的通知》（法〔2025〕82号，2025-05-28印发，2025-07-14起全面推广），共67类，覆盖刑事（自诉）、民事、商事、知识产权、海事、行政、环境资源、国家赔偿、执行9大领域；首批11类试行文本（法〔2024〕46号）同时废止。示范文本为"积极引导、尊重选择"，非强制；每类均配套【空白模板 + 官方填写实例】。
示范文本属于可选择的要素式路线，不因某案由已有示范文本就当然采用。用户、法院或任务明确要求使用法〔2025〕82号示范文本，或者用户提供该表单要求填写时，按要素式路线制作；其他从头起草任务默认按《民事诉讼法》(2023修正) 第一百二十四条（起诉状记明事项）、第一百二十八条（答辩状）的传统叙述式体例制作，以避免大量空白字段和不必要表格。

---

## 一、民事起诉状

### 1. 体例骨架（要素式示范文本）
1. 标题：居中「民事起诉状」，下行括注案由，如「（民间借贷纠纷）」
2. 具状人（签字、盖章）：＋ 日期：（置于标题下、表格前）
3. 填表说明栏：填写提示 + ★特别提示★（民诉法第十三条第一款诚信原则、虚假/恶意诉讼追责警示）
4. 【当事人信息】：原告（自然人／法人、非法人组织分栏）→ 委托诉讼代理人 → 被告 → 第三人
5. 【诉讼请求和依据】：按请求类型逐项列示（如本金／利息／解除合同／担保权利／实现债权费用／其他请求），末列「标的总额」「请求依据（合同约定＋法律规定）」
6. 【约定管辖和诉讼保全】：有无仲裁或法院管辖约定（注明合同条款及内容）；是否已诉前保全／申请诉讼保全
7. 【事实和理由】：按案由要素化分项（合同签订情况→签订主体→标的／金额→期限→履行情况→违约情况→担保情况→其他需要说明的内容）
8. 证据清单（表格末项，可另附页）

### 2. 体例骨架（传统叙述式，无示范文本案由适用）
标题「民事起诉状」→ 当事人栏（原告、被告、第三人、法定代理人/委托诉讼代理人）→ 诉讼请求（分项编号）→ 事实与理由 → 证据和证据来源，证人姓名和住所 → 「此致 ××××人民法院」→ 具状人签名（捺印）/盖章 → 日期 → 附项（起诉状副本×份、证据×组等）

#### 传统叙述式当事人栏的排版写法

- 默认一个主体一个自然段，将主体名称或姓名、住所、统一社会信用代码／身份信息、联系方式等已知字段以全角逗号连接，不为每个字段另起一行。
- 法人示例：`原告：××有限公司，住所地××省××市××区××路×号，统一社会信用代码：____。` 下一段写 `法定代表人：××，职务：××。`
- 自然人示例：`被告：××，男，××年×月出生，×族，住××，公民身份号码：____，联系电话：____。`
- 信息在页宽处自然换行仍属于同一段；不得在姓名、住所、证件号码等字段之间手工换行，不得为了少量占位符生成空白信息表。
- 当事人多时仍按主体逐段排列。只有用户或法院明确要求本文件采用法〔2025〕82号要素式示范文本，才切换为上文的当事人信息表格。

#### 传统叙述式正文结构

- 诉讼请求使用“一、二、三”编号，每项保持判项式短句，不制作请求事项表格。
- “事实与理由”按请求权、抗辩或程序争点分节；小标题优先直接写明结论，例如“案涉合同已明确约定两被告承担……”，不使用“关于合同责任”等空泛标题。
- 事实较简单时在论证中按时间自然叙述；只有事件密集且需要同时核对日期、主体、行为和证据时才另设时间线表。
- 独立证据清单原则上使用“序号／证据名称／证明目的”表格。正文中偶然提及少量证据不等于必须另建证据表。

### 3. 必备要素清单（民诉法第一百二十四条 + 示范文本当事人栏）
- 原告（自然人）：姓名、性别、出生日期、民族、工作单位及职务、联系电话、住所地（户籍所在地）、经常居住地、证件类型及号码
- 原告（法人、非法人组织）：名称、住所地（主要办事机构所在地）、注册地/登记地、法定代表人或主要负责人（姓名、职务、联系电话）、统一社会信用代码、组织类型（勾选：有限责任公司/股份有限公司/事业单位/社会团体/合伙企业等）
- 被告：自然人写姓名、性别、出生日期、民族、工作单位、住所地、经常居住地等；法人写名称、住所地、法定代表人、统一社会信用代码等（被告信息按已知尽量填写）
- 委托诉讼代理人：有/无；姓名、单位、职务、联系电话、代理权限（一般授权/特别授权）
- 诉讼请求：具体、明确、分项，含金额和计算方式
- 事实与理由、证据和证据来源（证人姓名和住所）

### 4. 填写要点（官方填写说明）
- 勾选项打「√」；与本案无关的项目填「无」或不填；重要内容表格容纳不下的在表尾或另附页填写
- 金额：默认人民币，外币需特别注明；利息等持续发生的请求写明「截至×年×月×日止」金额＋计算方式＋是否请求支付至实际清偿之日止
- 请求依据分两栏：合同约定（写明合同名称及条款序号）＋ 法律规定（写明法律名称及条文）
- 「标的总额」单独列明（可注明「暂计至×年×月×日」）
- 落款：自然人由本人签名并捺印；法人、非法人组织加盖公章并由法定代表人签名或盖章；日期为提交起诉状之日
- 份数：按被告（及第三人）人数提出副本，即提交份数 = 对方人数 + 1
- 随状提交身份材料（身份证复印件、营业执照复印件等）；委托代理的附授权委托书
- 2025年82号版较首批的变化：删除「送达地址」「电子送达」栏目（立案时另行填写送达地址确认书）；诉讼请求、事实与理由项下增设空白栏供补充陈述；对专业术语增加解释和填写说明

### 5. 常见错误（官方说明提示）
- 不如实填写、进行虚假/恶意诉讼——将依法追究责任（★特别提示★专门警示）
- 诉讼请求不具体：只写「要求还钱」不写金额、利息起止时间和计算标准
- 漏填「是否请求支付至实际清偿之日止」，导致利息主张截止日不明
- 主张担保权利、实现债权费用（律师费、保全费等）未列明内容/明细
- 漏交身份证明材料；落款未签名捺印或未盖章；漏列证据清单

## 二、民事答辩状

### 1. 体例骨架（要素式示范文本）
1. 标题：居中「民事答辩状」，下行括注案由
2. 答辩人（签字、盖章）：＋ 日期：
3. 填表说明栏 + ★特别提示★（同起诉状，诚信诉讼警示）
4. 【案号｜案由】栏：填写法院已立案的案号（如「（20××）×××民初×××号」）和案由——此为答辩状特有栏目
5. 【当事人信息】：仅填答辩人（自然人／法人、非法人组织分栏）＋ 委托诉讼代理人
6. 【答辩事项和依据】（对原告诉讼请求的确认或者异议）：逐项对应起诉状各项诉请，勾选「无」异议或「有」异议＋事实和理由；末项「答辩依据（合同约定＋法律规定）」
7. 【事实和理由】（对起诉状事实和理由的确认或者异议）：逐项对应起诉状事实要素，勾选无/有异议并说明；另设「有无其他免责/减责事由」「其他需要说明的内容」
8. 证据清单（可另附页）

### 2. 体例骨架（传统叙述式）
标题「民事答辩状」→ 答辩人栏（基本信息，可注明「因×××诉答辩人×××纠纷一案〔案号〕，提出答辩如下」）→ 答辩意见（针对诉讼请求逐项回应，分项编号）→ 事实与理由 → 证据 → 「此致 ××××人民法院」→ 答辩人签名（捺印）/盖章 → 日期 → 附项

传统答辩状沿用起诉状的紧凑当事人栏：一个答辩主体一个自然段，已知字段以逗号连接；法定代表人另起一段。答辩请求或总体答辩意见保持编号短句，不使用表格。正文以原告诉请或争议焦点为轴，使用能够直接表达结论的小标题逐项回应。正式证据清单使用表格，法律论证不表格化。

### 3. 必备要素清单（民诉法第一百二十八条 + 示范文本）
- 答辩人（自然人）：姓名、性别、出生日期（年龄）、民族、职业/工作单位、联系电话、住所地、经常居住地
- 答辩人（法人、非法人组织）：名称、住所地、注册地/登记地、法定代表人或主要负责人（姓名、职务、联系电话）、统一社会信用代码、组织类型
- 案号、案由（照抄法院应诉通知书/起诉状副本）
- 委托诉讼代理人信息及代理权限
- 答辩意见：对每项诉讼请求明确表态（认可或反驳）及依据
- 对事实的确认或异议、免责/减责事由、证据清单

### 4. 填写要点（官方填写说明）
- 答辩采「逐项对应」结构：起诉状的每一项诉请、每一项事实要素，均对应一行「无异议／有异议＋事实和理由」，不遗漏、不笼统
- 「无异议」的直接勾选即可，可缩小争点；「有异议」的必须写明事实和理由，不能只勾选
- 答辩依据与起诉状对称：分「合同约定」「法律规定」两栏列明
- 免责/减责事由（如诉讼时效、已履行、合同无效、不可抗力）在专门栏目主张
- 期限：应当在收到起诉状副本之日起十五日内提出答辩状；不提出答辩状的，不影响人民法院审理（民诉法第一百二十八条）
- 落款：自然人签名捺印，法人盖公章＋法定代表人签名；随状提交身份材料
- 请求性、和解性表达（如请求宽限、分期）写入「其他需要说明的内容」栏，不与异议混写

### 5. 常见错误（官方说明提示）
- 对诉请只表态不说理：勾「有异议」却不填事实和理由
- 全盘否认而不逐项回应，无法帮助法院归纳争议焦点
- 漏填案号、案由，法院无法对应在审案件
- 虚假陈述——同受诚信原则约束及虚假诉讼追责警示
- 将反诉请求写入答辩状（反诉应另行提起），或漏交证据清单
