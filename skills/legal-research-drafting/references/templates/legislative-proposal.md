# 立法建议书模板

通用结构参考。仅含体例与撰写方法，不含任何具体案情或项目内容。

立法建议书无官方统一模板。版式依据《党政机关公文处理工作条例》和 GB/T 9704-2012《党政机关公文格式》（A4 纸、标题—主送机关—正文—附件说明—署名—成文日期—附注—附件的要素编排）；内容结构沿用人大代表议案的"案由、案据、方案"三要素（《代表法》第十五条：议案应当有案由、案据和方案）；提交渠道与附加要求以征集方公告为准（全国人大常委会法工委法律草案征求意见公告、司法部/地方司法局立法项目建议征集公告等）。

## 体例骨架

1. 标题："关于制定《××法》的立法建议书" / "关于修改《××法》第×条的立法建议书"（事由+文种，居中）
2. 致送机关：顶格，如"全国人民代表大会常务委员会法制工作委员会："/"司法部："（按征集公告指定的受理机关写全称）
3. 建议人信息：姓名/单位名称、职业或研究领域（说明建议资格与专业关联）、通讯地址、电话、电子邮箱；单位提出的注明联系人
4. 案由——问题与立法必要性：现行法律缺失或条文缺陷导致的具体问题，立法解决的必要性、重要性、紧迫性
5. 案据——论证依据：
   - 现状分析：问题的表现、成因、影响范围（用数据和事实，注明来源）
   - 规范依据：上位法依据、相关政策文件、现行规定的冲突或空白点
   - 域内外经验：其他省市地方立法先例、域外立法例及其可借鉴之处
   - 司法与执法实践：典型判决反映的裁判分歧、执法困境
6. 方案——具体建议：
   - 制定新法的：建议的框架结构（章节+各章拟规定的主要制度），有条件的附草案建议文本
   - 修改现行法的：逐条列"修改对照表"（见撰写要点），并对每处修改附简要理由
7. 结语：提请研究采纳的请求语，简明扼要
8. 落款：建议人签名或单位盖章 + 成文日期（单位建议须加盖公章）
9. 附件：草案建议文本、修改对照表、调研数据、参考资料清单

## 必备要素清单

- [ ] 标题含拟立/拟修法律名称和"立法建议书"文种
- [ ] 致送机关为征集公告指定的受理机关全称
- [ ] 建议人身份与联系方式完整（单位建议加盖公章、注明联系人）
- [ ] 案由、案据、方案三部分齐备且一一对应
- [ ] 立法项目名称、必要性和可行性、拟解决的主要问题、拟确立的主要制度四项俱全（司法部历年征集公告的通用要求）
- [ ] 修改类建议附修改对照表；制定类建议附框架或草案建议文本
- [ ] 引用的现行条文经逐字核对并注明法律全称、条款项号和版本（年份）
- [ ] 落款签名/盖章与成文日期
- [ ] 按公告要求的渠道提交（在线平台/电子邮件/信函），信封或邮件主题按公告注明"××征求意见/立法项目建议"字样，并在截止日期前送达

## 撰写要点

- 一事一议：一份建议书只针对一部法律或一个立法项目，多个诉求分别成文。
- 三要素闭环：案由提出的每个问题，案据须有对应论证，方案须有对应条文回应；不留"有问题无方案"的断点。
- 修改对照表：修改现行法的建议一律用三栏表——"现行条文｜建议修改为｜修改理由"，逐条对照，条文全文引用而非节选大意；新增条文标"新增"，删除条文标"删除"并说明理由。
- 引用准确：引用现行条文须与官方文本（国家法律法规数据库 flk.npc.gov.cn）逐字一致，注意法律修正后的条文序号变动，引用时注明版本年份。
- 必要性论证：从问题的普遍性、危害性和现有制度不敷使用三个层面展开，用统计数据、典型事例和裁判分歧支撑，避免空泛的口号式表述。
- 可行性论证：说明立法条件成熟度——上位法空间、政策支持、地方或域外先行经验、社会共识程度、实施成本与配套制度；预判主要争议点并给出立法选择的理由。
- 方案具体化：拟确立的主要制度写到"条文级"精度（管辖机关、行为规则、法律责任、衔接条款），使承办机关可直接评估采纳。
- 语言与版式：公文语体，第三人称客观表述；A4 纸；层次序号依次用"一、""（一）""1.""（1）"；数字、标点用法遵循 GB/T 15835、GB/T 15834。
- 提交前核对征集公告：不同征集方对内容要项、附件形式（如立法项目建议表）、提交渠道和标注字样有具体要求，以当次公告为准。

## 常见错误

- 三要素残缺：只述问题不给方案，或方案笼统为"建议加强立法"，无具体条文或制度设计。
- 引用条文不准：凭记忆引用已被修正的旧条文、条号错位、法律名称简称不规范（首次出现未用全称）。
- 修改建议不用对照表，混在议论中表述，承办机关无法定位修改点。
- 把立法建议书写成学术论文：大篇幅文献综述和理论争鸣，缺少可操作的制度方案。
- 一份建议书夹带多个不相关立法诉求。
- 越权建议：建议事项超出受理机关职权（如向地方人大建议修改法律、地方立法建议超出立法法授权的城乡建设与管理、生态文明建设、历史文化保护、基层治理等事项范围）。
- 形式瑕疵：单位建议未盖公章、无联系方式、超过征集截止日期、未按公告注明标识字样，导致无法登记处理。
- 只提域外经验不作本土化论证，可行性部分流于"国外均有立法"。
