# 强制执行申请书(要素式示范文本)模板参考

依据最高人民法院、司法部、中华全国律师协会《关于印发部分案件起诉状答辩状示范文本的通知》(法〔2025〕82号)之"执行类 9 种"官方 word 模板整理。示范文本为**表格化、要素式、勾选式**文书(勾选项打"√"),与传统叙述式申请书并行:法院应尊重当事人选择,不得以不符合示范文本为由拒收传统文书。

## 一、体例骨架(强制执行申请书,申请执行用)

1. **标题**:强制执行申请书,下注小字"(申请执行用)"
2. **说明栏**(表格首行,模板自带,勿删改):填表须知、随附材料清单、勾选/扩容规则、诚信填报与财产线索特别提示
3. **当事人信息**(表格):申请执行人 → 委托诉讼代理人 → 被执行人(可复制粘贴增加多方)
4. **执行依据信息**(表格):文书类型(勾选)/作出机构/案由/文书号/生效日期/执行依据判项主文
5. **申请执行事项**(表格):先概括描述请求与事实理由,再按要素勾选填写分项金额
6. **保全与财产线索**(表格):诉前/诉讼保全情况、其他财产线索
7. **落款**:申请执行人(签字、盖章)+ 日期。**注意:要素式文本无"此致××人民法院"行**,递交时向有管辖权的执行法院提交;如改写为传统叙述式申请书,则须在正文末写"此致 ××人民法院"

## 二、必备要素清单

**申请执行人栏**
- 自然人:姓名/性别/出生日期/民族/工作单位及职务/联系电话/住所地(户籍所在地)/经常居住地/证件类型与号码/**银行账号+开户名+开户行**(用于案款发还,必填)
- 法人、非法人组织:名称/住所地(主要办事机构所在地)/注册地(登记地)/法定代表人或负责人及职务/联系电话/统一社会信用代码/银行账号信息/组织类型勾选/所有制性质勾选
- 委托诉讼代理人:有无、姓名、单位、职务、联系电话、代理权限(一般授权/特别授权)

**被执行人栏**:项目同上但**无银行账号栏**;多个被执行人逐一复制表格填写

**执行依据栏**
- 文书类型勾选四大类:民事类(判决书/裁定书/调解书/制裁决定/支付令)、刑事类(刑附民判决/裁定/调解书)、行政类(判决/裁定/调解书、行政处罚决定、行政处理决定)、仲裁公证类(裁决书/调解书/保全裁定/赋予强制执行效力的债权文书)
- 表述格式:作出机构(全称,如"××省高级人民法院"或仲裁委、公证处)+ 案由 + 文书号(如"(20××)×民终××号")+ 生效日期(×年×月×日)+ **执行依据判项主文逐项照抄**(给付内容、履行期限、责任范围如"在××万元范围内承担"须原文摘录)

**申请执行事项分项**(勾选+填数)
- 金钱给付:本金□___ / 一般债务利息□___ / 迟延履行利息□___ / 其他费用□___(如申请执行费由被执行人负担)
- 行为执行□ / 交付特定物□ / 其他□(如"拍卖被执行人名下××资产")

**财产线索栏**:诉前/诉讼保全(有则填保全案号+保全措施最早到期时间,便于法院及时续封)、其他财产线索(逐项列明财产种类与所在,如不动产、采矿权、账户等)

## 三、填写要点

- **生效日期与申请期间**:生效日期按执行依据实际生效日填写(一审满上诉期未上诉、二审自送达、调解书自签收)。申请执行期间二年,自法律文书规定履行期间最后一日起算;分期履行的自最后一期履行期限届满之日起算;未规定履行期间的自文书生效之日起算(《民事诉讼法(2023修正)》第250条,[条文](https://ydzk.chineselaw.com/zxt/statuteDetail/detailPage/f1b65a4dca3d6472206978435e2ea215?text=250))
- **加倍利息(迟延履行利息)规范写法**:依据《民事诉讼法(2023修正)》第264条([条文](https://ydzk.chineselaw.com/zxt/statuteDetail/detailPage/f1b65a4dca3d6472206978435e2ea215?text=264))及法释〔2014〕8号解释,勾选"迟延履行利息"并写明:"自×年×月×日(履行期届满次日)起至实际履行完毕之日止,以未履行的金钱债务本金为基数按日万分之一点七五计算加倍部分债务利息";一般债务利息按生效文书确定的标准另行填写,两者勿混同
- **判项主文与请求对应**:申请执行事项不得超出判项主文范围;已部分履行的按剩余数额填写(官方实例即将判项 1800 万元本金按已还情况填 1600 万元)
- **概括描述栏写法**:一句话式,"××号××书已经生效,但被执行人×××未按××书确定的义务履行,请求按××书执行"
- **致送法院**:向第一审法院或与其同级的被执行财产所在地法院递交;行政处罚决定、行政处理决定须先经法院裁定准予执行;公证债权文书须一并提交执行证书(模板"文书类型"栏注记)
- **随附材料**:身份材料、生效法律文书副本及生效证明、继承或权利承受证明(如有);表内无关项目填"无"或不填;栏目可扩容、复制,但不得改变要素内容与格式设置

## 四、常见错误

1. 漏填申请执行人银行账号/开户行,影响执行案款发还
2. 执行依据判项主文摘抄不全或改写,遗漏履行期限、担保人责任限额等关键判项
3. 迟延履行利息与一般债务利息混填一栏,或加倍利息未写明起算日与"日万分之一点七五"标准
4. 未扣除已履行部分,申请金额超出判项范围
5. 有诉讼保全却漏填保全案号与到期时间,导致查封续封脱节
6. 分期履行文书误从第一期届满起算申请期间(现行规则为最后一期届满之日起算)
7. 基于捏造事实的仲裁裁决、调解书、公证债权文书申请执行——模板特别提示将依法追责

## 五、执行类其余 8 种文书一览(法〔2025〕82号执行类共 9 种)

| 文书名称 | 适用场景 |
|---|---|
| 执行异议申请书 | 当事人、利害关系人认为执行行为违法,或案外人对执行标的有异议,向执行法院书面提出 |
| 执行复议申请书 | 当事人、利害关系人对执行异议裁定(不予受理/驳回)不服,裁定送达之日起 10 日内向上一级法院申请 |
| 执行监督申请书 | 对执行复议裁定仍不服,裁定生效后 6 个月内向上一级法院申请监督 |
| 不予执行申请书 | 被执行人或案外人申请不予执行仲裁裁决、仲裁调解书或公证债权文书(注意 15 日/30 日期限) |
| 执行担保申请书 | 被执行人或第三人提供执行担保、经申请执行人同意后申请暂缓执行 |
| 参与分配申请书 | 被执行人为公民或其他组织、财产不能清偿所有债权时,其他已取得执行依据的债权人申请参与案款分配 |
| 确认优先购买权申请书 | 网络司法拍卖中,优先购买权人申请法院确认资格以取得优先竞买代码参拍 |
| 暂时解除乘坐飞机、高铁限制措施申请书 | 被限消人因本人/近亲属重大疾病就医、丧葬、执行公务、重要考试等紧急事由申请单次解禁 |

共性:9 种均为"标题+(用途注记)+说明栏+当事人信息表+事项/理由要素表+签字盖章落款"结构,均附官方填写实例,均可勾选、扩容但不得改变要素与格式。
