# 民事上诉状（官方模板格式与填写要点）

依据：最高法《民事诉讼文书样式》（法〔2016〕221号，当事人文书部分"民事上诉状〔当事人提起上诉用〕"样式及【说明】），条文引用已换算为《民事诉讼法（2023修正）》现行条号。

## 一、体例骨架

```
民事上诉状
上诉人（原审诉讼地位）：×××，男/女，××××年××月××日出生，×族，……（写明工作单位和职务或者职业），住……。联系方式：……。
法定代理人/指定代理人：×××，……。
委托诉讼代理人：×××，……。
被上诉人（原审诉讼地位）：×××，……。
（以上写明当事人和其他诉讼参加人的姓名或者名称等基本信息）

上诉人因与被上诉人××××（写明案由）一案，不服××××人民法院××××年××月××日作出的（××××）……民初……号民事判决/裁定，现提起上诉。

上诉请求：
一、……
二、……
上诉理由：
一、……（有新证据的，在上诉理由之后写明证据和证据来源，证人姓名和住所）

此致
××××人民法院

附：本上诉状副本×份

                                        上诉人（签名或者盖章）
                                        ××××年××月××日
```

## 二、必备要素清单（民诉法第172条法定内容）

- [ ] 标题"民事上诉状"（勿只写"上诉状"，以免与刑事、行政上诉状混淆）
- [ ] 上诉人、被上诉人姓名/名称及基本信息，诉讼地位后括注原审诉讼地位，如"上诉人（原审被告）"
- [ ] 法人/其他组织：名称、住所，另起一行写法定代表人/主要负责人姓名、职务、联系方式
- [ ] 案由（与一审裁判文书列明的案由一致）
- [ ] 原审法院全称、裁判作出日期、案号、文书种类（判决/裁定）
- [ ] 上诉请求（分项列明）、上诉理由
- [ ] 致送法院（二审法院全称）、附项（副本份数）、签名/盖章、具状日期

## 三、填写要点

0. **版式与信息密度**：当事人栏采用紧凑段落，一个主体一个自然段，姓名／名称、住所、身份信息、联系方式等已知字段以全角逗号衔接；法人法定代表人信息另起一段。不要把每个字段拆成一行，也不要将传统上诉状改造成当事人信息表。标题下直接进入当事人栏和案件引入，不增加封面。
1. **一审裁判文书引用格式**：`不服××××人民法院××××年××月××日作出的（××××）×民初××××号民事判决`。案号照抄一审文书（年份+法院代字+类型代字"民初"+序号），法院用全称；判决与裁定必须写准，二者上诉期不同。
2. **上诉请求"撤销与改判对应"的规范写法**：
   - 全部不服：`一、撤销（××××）×民初××××号民事判决；二、依法改判……（写明具体改判内容）/发回重审；三、一、二审诉讼费用由被上诉人负担。`
   - 部分不服：`一、撤销（××××）×民初××××号民事判决第×项；二、依法改判……`——撤销的判项范围与请求改判的内容必须一一对应，未上诉的判项不列入撤销范围；改判请求应像诉讼请求一样明确、具体、可执行（写明金额、履行方式），不能只写"依法改判"。
   - 管辖权异议上诉（样式固定两项）：`一、撤销××××人民法院（××××）×民初××××号民事裁定；二、本案移送××××人民法院处理（或：本案由××××人民法院管辖）。`
3. **上诉期表述**：不服一审判决，判决书送达之日起15日内；不服一审裁定（可上诉的仅不予受理、驳回起诉、管辖权异议三种），裁定书送达之日起10日内；在我国领域内无住所的当事人为30日（民诉法第171条、第286条）。期间自送达之次日起算。状内无需专段声明，但具状日期须落在上诉期内。
4. **副本份数附项**：`附：本上诉状副本×份`——按对方当事人或者代表人的人数提交（民诉法第173条）。上诉状通过原审法院提出；直接递交二审法院的，二审法院5日内移交原审法院。
5. **上诉理由**：针对原审裁判而非对方当事人，围绕（1）认定事实不清、主要证据不足，（2）定性不当，（3）适用法律错误，（4）违反法定程序四类展开，逐项对应判决书的认定与说理。
6. **落款**：自然人由本人签名或盖章；法人/其他组织署单位全称加盖公章，并由法定代表人/主要负责人签名。

### 版式与论证组织

- 案件引入段应一次性交代案由、原审法院、裁判日期、案号、裁判种类和提起上诉，不把这些字段拆成表格。
- 主位请求、备位请求直接在编号请求中标注，例如`一、（主位请求）……；二、（备位请求）……`，不另建方案比较表。
- 上诉理由使用结论式小标题并直接针对原审裁判，例如“原审未经有效送达即公告并缺席审理，程序保障存在重大欠缺”；避免仅写“关于程序问题”“关于证据问题”。
- 上诉理由属于连续说理，不制作“原审观点／上诉人观点／依据”之类的机械表格。只有确有新证据时，证据清单单独使用表格。

## 四、常见错误

- 上诉请求只写"撤销原判、依法改判"而无具体改判内容；或部分上诉却请求撤销全部判项，撤销范围与改判范围不对应。
- 案号、文书种类抄错（把裁定写成判决），或对不可上诉的裁定（如财产保全裁定）、调解书提起上诉。
- 漏写原审诉讼地位括注、案由，或当事人信息与一审文书不一致。
- 只在口头表示上诉而未在法定期限内递交书面上诉状（视为未上诉）；具状日期超上诉期。
- 副本份数与对方当事人人数不符；直接寄二审法院导致周转延误。
- 签名用打印体而非亲笔签名/盖章（可能被退回）；漏交上诉费（通知后仍不交按自动撤回上诉处理）。
- 把上诉状写成对对方当事人的指责（起诉状写法），未针对一审裁判本身。
