# 企业主体核验

先读[方法与输入输出](references/contract.md)，使用`scripts/client.py`调用清言代理。当前环境根地址已经内置；第三方Token由后端注入，不读取用户登录文件；

1. 仅在用户要求或主体核验会实质影响结论时查询，不自动为每份合同产生付费调用。同一任务已有可用结果不重复查询。
2. 企业简称、重名或目标不清晰时先`search_company`；返回多个候选则由用户确认。详情使用已确认的企业全称作为`keyword`，不在未确认时猜测主体，也不擅自改用企业编号重复付费查询。
3. `get_basic_info`仅取得基本工商字段。没有返回的字段留空，不补造股东、处罚、涉诉或信用结论。
4. 展示企业名称、所需工商字段、数据来源“天眼查”和查询日期；无真实URL时不制造“点击查看”链接。天眼查是第三方快照，不等于官方登记证明。
5. 空结果如实说明；错误或未知响应不称为“未收录”。辅助查询失败不阻断普通条款审查，只标记主体核验未完成。
6. 不访问任意接口path、不保留239项目录或余额查询。费用与额度由平台管理，不要求终端用户充值外部服务或填写Key。

## 执行

路径按实际安装目录解析；下例相对含`skills/`的工作区根：

```bash
python3 skills/tianyancha/scripts/client.py --input '{"operation":"search_company","keyword":"企业名称","page_size":10,"page_number":1}'
python3 skills/tianyancha/scripts/client.py --input '{"operation":"get_basic_info","keyword":"已确认的企业全称"}'
```

真实调用不加`--response-file`或`--dry-run`。企业搜索已返回真实候选。基本信息旧路径因上游接口未开通曾返回`300005`；当前客户端已切换到研发指定的V2路径。在新路径完成真实回归前，不把历史错误当作当前必然状态，也不得把搜索快照冒充详情。
